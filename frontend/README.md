# frontend

React + Vite + TypeScript dashboard: change log, change detail, incidents, evidence, postmortem
editor. `src/api/` is the only place that calls the backend; its types are generated from
[`../openapi.yaml`](../openapi.yaml). Screens follow [`../docs/mockups/`](../docs/mockups/).

Filled by the frontend + change log workstream (no issue filed yet).
