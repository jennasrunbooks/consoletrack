# terraform/consoletrack/us-east-1

Regional platform, created and destroyed freely: VPC with a fck-nat instance, EKS with a Spot
node group, Pod Identity roles, change intake (CloudTrail, EventBridge, SQS), the canary
security group, ACM, and third-party Helm add-ons.

Filled by the EKS + deploy pipeline and change intake workstreams (no issue filed yet).
